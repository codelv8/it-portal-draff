# Quick Launch Menus — verification

Date: 2026-10-25. Local synthetic browser checks only; no backend, database migration, authentication or deployment change.

## Implemented behavior

All admin workspace pages share the floating launcher through `assets/js/app.js`; Login/public pages remain excluded. The fullscreen overlay searches read-only system navigation and browser-local personal cards. Personal add/edit/delete use the shared modal, native field validation, dirty-discard confirmation and storage error feedback. Theme tokens, existing buttons/icons and responsive layout are retained in `assets/css/styles.css`. User data lives independently at `it-portal-quick-launch-v1`, with stable IDs, insertion order and no application count limit. HTTP development hosts without `crypto.randomUUID()` use random IDs generated by `crypto.getRandomValues()`.
